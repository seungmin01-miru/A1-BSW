# 실차 신호·명령 한계 검증 매뉴얼 (v2, 2026-11-02)

목표: **원격으로 차량의 물리 한계(상한)를 찾고 → 같은 범위에서 우리 0x210 명령의 응답을 맞춰 보고 → 제어기 클램프에 반영한다.**

**시험 조건 (공간 제약)**: 조향은 **앞바퀴를 땅에 둔 정지 상태**, 가감속은 **뒷바퀴를 띄운 공회전**으로 한다.

각가속도)·불감대·지연·응답 모양만 얻고, **m/s² 매칭은 11-04 주행**(TRACK_MANUAL T3·T4)에서 한다.

## 안전 규칙 (전 단계)

1. **0x210 송신자는 하나.** 1단계는 우리가 아무것도 보내지 않는다(listen-only). 2단계에서만 can_guard 하나가 보낸다.
2. 원격(0x156 En=1)이 0x210 보다 우선한다 → 2단계 중 문제가 생기면 **원격 담당이 En 을 켜서 넘겨받는 것**이 첫 번째 정지 수단.
3. **0x210 타임아웃이 없다**(10-07: 60 s 끊겨도 auto 유지). 2단계 끝은 항상 lift_cmd `auto off` → 0x200 auto 000 확인 → `q` → `stop.sh`.
4. **공회전 규칙**
   - 뒷바퀴 받침(스탠드·리프트)이 단단한지 시작 전 확인. 앞바퀴는 고임목.
   - 뒷바퀴 주변 2 m 출입 금지(안전 담당). 손·공구·케이블이 바퀴 근처에 없을 것.
   - **바퀴 속도 상한을 정하고**(예: 30 km/h — 업체와 합의, V18) 넘으면 즉시 가속 0. 부하가 없어 순식간에 오른다.
   - 가속은 **낮은 값부터**, 한 계단 3 s 이내. 계단 사이에 바퀴가 멈출 때까지 기다린다.
   - 브레이크는 **고속 공회전 중 세게 걸지 않는다**(구동계 충격) — 저속(10 km/h 이하)에서 약하게부터.
5. **조향(정지, 땅)**: 정지 상태 끝까지 조향은 업체 허락(V17)이 있을 때만. 끝에서 오래 붙잡지 않는다(5 s 이내).
6. **중단 기준** — 하나라도 보이면 즉시 멈추고(원격: 놓기 / 우리: `zero` → `auto off`) 원인부터 본다:
   명령과 반대 방향으로 움직임 · 0x200 카운터 정지 · 에러프레임 증가 · 예상 밖 0x210 송신자 · can_guard 송신 실패 누적 ·
   조향 모터·구동계 이상음 · 받침 흔들림 · 브레이크 위치가 명령 없이 변함(10-07 10:58 처럼) · 모터 컨트롤러 오류 표시.

## 1단계: 원격으로 물리 한계 찾기 (60분)

우리는 **듣기만** 한다. 원격 담당이 조작하고, PC 담당은 단계마다 `m` 으로 시작·끝을 찍는다.
단계가 끝날 때마다 그림을 보고 다음 단계로 간다 — 이상하면 거기서 멈춘다.

### 원격 조작 표 (원격 담당에게 출력해서 건넴)

| 단계 | 조건 | 조작 | 유지 |
|---|---|---|---|
| L1-a | 정지, 앞바퀴 땅 | 핸들 **왼쪽 끝까지 천천히**(약 5초에 걸쳐) → 유지 → 가운데 | 끝에서 3~5 s |
| L1-b | 같음 | **오른쪽 끝까지 천천히** → 유지 → 가운데 | 끝에서 3~5 s |

- **최대 조향 속도** = `limits.md` 조향 속도 p99/최대 (L1-c). 10-07: 최대 약 126 °/s. 정지 상태라 주행보다 느릴 수 있다
  (타이어 마찰 최대) — 주행 시 조향 속도 한계로 쓰면 보수적.

## 2단계: 0x210 응답 (50분)

원격은 **En=0 (대기)**, 우리가 can_guard 로 보낸다. 원격 담당은 언제든 En 을 켜서 넘겨받을 수 있게 대기.
L0 에서 원격이 0x210 을 보냈다면 **원격 유닛을 끈다**(can_guard 가 다른 0x210 을 보면 시작 거부, 종료 코드 3).

### 2-0. 띄우기 (5분)
```bash
# 터미널 0: listen-only 미러 Ctrl+C (1단계 녹화 종료)
m "1단계 녹화 종료, 2단계 bringup"
bash ~/git/A1-BSW/tools/track_day/bringup.sh --kvaser 0 --no-adapter --out "$D/l4" --acc-limit 10
```
- `bringup.sh` 가 미러(normal)·can_guard·브리지·녹화를 `$D/l4/` 에 띄우고, **lift_cmd 실행 명령줄을 출력**한다 → 터미널 4 에서 실행.
- 출력된 lift_cmd 명령줄의 한계를 1단계에서 정한 값으로 **낮추고**(`--steer-limit-deg <정한 값>`), 가속 유지 시간을
  늘린다(`--acc-hold-s 3` — 기본 2 s 면 공회전 계단이 짧다). lift_cmd 가 한계 밖 입력을 거부한다.
- 실패 메시지는 TRACK_MANUAL T0 표.

### L4-1. 배율·부호 (정지, 5분) = TRACK_MANUAL T1
```
auto steer on
steer 1     → 0x200 약 +1° (×0.1 동작).  +11° 면 ×1 → 중단, 업체 확인
steer 10    → 약 +11°.  앞바퀴가 왼쪽? 오른쪽?  →  m "L4-1 +10 → 바퀴 __쪽"
steer -10   → 약 −11°  (10-07 에 음수는 안 해 봄 — 대칭 확인)
steer 0
auto off
```
→ 카드 `steer_command`·`steer_is_auto_command`·0x200 `steer_postion`(+ 방향) 판정.

### L4-2. 조향 범위 (정지, 15분) = TRACK_MANUAL T2
`auto steer on` → `steer 30 / 60 / 90 / 120 / <상한>` → 음수 같은 순서 → `steer 0` → `auto off`.
- 조향은 5 s 뒤 자동 원위치 — 재는 동안 같은 명령을 다시 입력.
- L1b 를 못 했으면 여기서 타이어각을 잰다.
- 확인: `limits.png` "0x210 조향 → 0x200 위치"가 원격(L1)과 같은 선 위에 있는가.

### L4-3. 브레이크 %→위치 (바퀴 정지, 10분)
```
auto brake on
brake 10 / 30 / 50 / 70 / 100      (각 3 s, 사이에 brake 0)
brake 0
auto off
```
- 브레이크 위치 = 명령 ÷ 10 인지(10-07: 20/30/50 % 확인), 100 % 에서 10.0 인지, 어디서 포화하는지.
- 바퀴가 서 있으니 감속은 없다 — **% ↔ m/s² 는 11-04 주행 T3**.

### L4-4. 가속 공회전 (15분)
```
auto acc on
acc 3  → (바퀴 멈출 때까지 대기) → acc 5 → acc 7 → acc 10        (각 3 s, 넘으면 즉시 acc 0)
acc 0
auto brake on → brake 10 (바퀴 10 km/h 이하에서) → brake 0
auto off
```
- 확인 (`freespin.png` 왼쪽, `limits.md` 5절 "요약"):
  - **불감대** — 바퀴가 처음 도는 % (10-07 은 60 % 까지도 0 → 이번에 돌면 그 차이도 기록).
  - **지연** — 명령 → rpm 변화.
  - **모양** — 일정 속도에서 멈추면(정착) 가속 % = 목표 속도일 가능성, 계속 오르면 토크 명령(V3).
- 바퀴가 안 돌면 더 올리지 않는다(V11). 상한 안에서만 `--acc-limit` 을 올려(bringup 재시작) 한 계단씩.
- **% ↔ m/s² 는 11-04 주행 T4.**
