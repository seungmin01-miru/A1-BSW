# 논문용 데이터 체크리스트 — 전력 제한 하이브리드 CPU 에서 PREEMPT_RT CAN 게이트웨이의 지연·전력 동시 최적화

> 목적: 실차 적용 이후 논문(1차 목표 국내 학회, 2차 국제 워크숍/응용 트랙)에 필요한 데이터를 빠짐없이 모으기 위한 체크리스트.
> 규칙: 논문에 쓸 데이터를 새로 얻을 때마다 **이 파일의 해당 행을 갱신하고 커밋**한다. 상태 = `[ ]` 미착수 / `[~]` 부분 / `[x]` 완료. 모든 수치는 `measurements/*/README.md` 를 1차 출처로 하고 여기엔 요약과 경로만 둔다.
> 최종 갱신: 2026-09-17

## 0. 가제·기여 후보 (초안, 데이터가 쌓이면 수정)

**가제**: 전력 제한 하이브리드 CPU 에서 PREEMPT_RT 기반 CAN 게이트웨이의 지연·전력 동시 최적화 — 자율주행 경주차 적용 사례
(Latency–Power Co-optimization of a PREEMPT_RT CAN Gateway on a Power-capped Hybrid CPU: an Autonomous Racing Case)

| # | 기여 후보 | 현재 근거 | 논문 등급으로 올리려면 |
|---|---|---|---|
| C1 | `idle=poll` 과 `intel_pstate=disable` 은 **단독 무효, 조합에서만 유효** (12세대 P+E, HWP, 6.8-rt) | B1 640 / B2 813 / B 43·157 µs (`2026-09-16_bisect`) | 조건당 3회 반복 + 기전(§3) |
| C2 | 격리 코어 클럭을 **낮추면**(800 MHz) 최악값이 개선 (157 → 67 → 27) | `2026-09-16_eco` | 3회 반복 + RAPL/HWP 상태 덤프로 해석 |
| C3 | `schedutil` 은 PREEMPT_RT 에서 유휴 클럭을 내리지 못함(IRQ 스레드 FIFO → 최대) → `ondemand` 로 유휴 35 → 14 W | `2026-09-16_eco` 3차 | 커널 코드 근거(`sugov_get_util`/`effective_cpu_util` RT 규칙) 인용 + time_in_state 표 |
| C4 | PL1 35 W 소비자 CPU 에서 **최악 27 µs(30분) / 920 µs(8h) + 유휴 14 W** 양립 | `2026-09-16_eco`, `2026-09-17_8h_prod` | 대회 조건 8h + 실차 |
| C5 | 방법론: 무인 soak, overflow 사이클→시각 복원으로 에피소드–저널 대조, RAPL·MSR 동시 기록 | `tools/rt/*`, `2026-09-17_8h_prod` | 도구 공개(리포지토리 링크) |
