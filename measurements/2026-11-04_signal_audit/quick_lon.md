## 3. 현장에서 나온 문제

| 문제 | 내용 | 조치 |
|---|---|---|
| bringup RT 실패 | `sudo -v` 후 `setsid` 로 띄운 `sudo chrt` 가 터미널 없어 비밀번호 재요구 → can_guard 안 뜸 | 오늘은 `--no-rt`. 수정 필요(sudoers NOPASSWD for chrt, 또는 sudo 를 setsid 밖에서) |
| 앱이 ESTOP 유발 | 앱 enable/정지 상태에서 0x156 `01 96 01 …`(EPS_En·ACC_En=1), 0x157 `00 00 00 FF 03 …` → can_guard INIT → ESTOP | 앱에서 해제(0x156 `00 96 00 …`) 후 재기동. **앱 정지 프레임 후보** — 00-0 에서 재확인 |
| SIL E2(SIGUSR1) FAIL | `--rt` 일 때 시험이 sudo 래퍼에 신호를 보냄(추정, sudo 가 같은 프로세스 그룹 신호를 중계 안 함) | 시험 코드 수정 예정. `es`(공유메모리)·앱(0x156) 경로는 PASS |
