## 2. 이상 현상

### 2-1. ⚠️ CAN 재연결 때 0x210 몰림 송신
- 11:17:57.663~11:17:58.0 사이 0x210 **715개**가 프레임 간격 약 0.25 ms 로 연달아 나갔다. 내용은 전부 `00…00`(auto 0, 명령 0).
- 직전 11:12:45~11:17:58 은 사용자가 CAN 을 뺀 구간이고, can_guard 로그에 `canWriteSync … Timeout` 송신 실패가 쌓였다.
- 해석: 끊긴 동안 Kvaser 송신 버퍼에 남은 프레임이 연결되자마자 한꺼번에 나간 것으로 보인다. 이번에는 내용이 0 이라
  무해했지만, **주행 명령이었다면 수 초 전 명령이 재생**된다.
- 대책: 송신 실패가 나면 송신 버퍼를 비운다(python-can `flush_tx_buffer()` / CANlib `canFlushTransmitQueue`).
  재연결 직후 첫 명령은 auto 0 으로 시작한다.

### 2-2. ⚠️ 미확인 0x210 송신자

## 4. 액추에이터 역산

### 4-1. 조향 (can_guard 명령, 11:27~11:29, 차량 리프트 위)

| 명령 | 시작 위치 | 정착 위치 | 정착/명령 | 최대 속도 |
|---|---|---|---|---|
| 0 → +1° | −1.6° | +0.7° | — | 48 °/s |
| +1 → 0° | +0.7° | +0.7° (안 움직임) | — | — |
| 0 → +3° | +0.7° | +2.31° | 0.77 | 31 °/s |
| +3 → 0° | +2.3° | +0.1° | — | 43 °/s |
| 0 → +8° | +0.1° | +8.80° | 1.10 | 126 °/s |
| +8 → 0° | +8.8° | −1.4° | — | 100 °/s |
| 0 → +10° | −1.4° | +11.00° | 1.10 | 126 °/s |
| +10 → 0° | +11.0° | −0.6° | — | 102 °/s |

- **이득**: 큰 계단에서 위치 ≈ 명령 × 1.10. 작은 계단에서는 불감대 때문에 맞지 않는다.
- **불감대·히스테리시스**: 명령 0° 에서 정착 위치가 −1.6~+0.7° 로 흩어지고, 1° 변화에는 움직이지 않은 적이 있다 → 약 ±1.5°.
- **최대 속도**: 8° 와 10° 계단이 같은 126 °/s(42 ms 두 프레임 차분, 분해능 약 2.4 °/s) → **약 125 °/s 에서 포화됐을 가능성**.
  더 큰 계단으로 확인해야 한다.
- **운동 범위**: 관측 −3.5~+11.0° 뿐. DBC 상 명령 ±150°, 위치 ±200°. 실제 끝 각도는 미측정.
- 모델(잠정): 무반응 약 0.175 s + 1차 지연(시정수 약 0.03~0.08 s) + 속도 제한 약 125 °/s + ±1.5° 불감대.
