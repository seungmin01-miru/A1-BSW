## 목적
- 계단·램프·사다리꼴 명령을 설정값만 바꿔 반복 입력하는 생성기를 만든다 (03·04·07 공용).

## 전제 조건
- [ ] can_guard 와의 연결 경로 결정 (CommandChannel 직접 / 제어기→어댑터 경유)
- [ ] SIL(vcan) 환경

## 입력 (명령 조건)
| 단계 | 출력 | 프로파일 | 설정값 |
|---|---|---|---|
| 1 | 가속 % / 브레이크 % / 핸들 ° (개루프) | 계단·램프·사다리꼴·사인 | 목표값, 기울기, 유지 시간, 주파수 |
| 2 | 목표 속도 km/h (폐루프, 속도 제어기 필요) | 계단·램프·사다리꼴 | 목표속도, 기울기, 유지 시간 |

- 설정 파일(yaml) 하나로 회차를 재현. 회차 이름(`날짜_ID_회차`)을 받아 명령 로그 파일명에 사용.

## 측정 신호
- [ ] 생성기 명령 로그 (시각, 프로파일 종류, 명령값)
- [ ] 0x210 실제 송신값 (vcan / 실차)

## 합격 기준
> 숫자는 **초기 가정치**(`../../docs/test_plan.md`). 첫 주행 뒤 조정 제안은 results.md "다음 조치"에.

| 지표 | 기준값 | 계산 방법 |
|---|---|---|
| 프로파일 3종(+사인) 설정값만으로 재사용 | 가능 | 코드 수정 없이 yaml 만 변경 |
| 최대값 제한 내장 | 상한 초과 명령 0건 | 상한 + can_guard 클램프 이중 |
| 명령 로그 | 모든 명령 기록, 0x210 과 1주기(20 ms) 안 일치 | vcan 로그 대조 |
| SIL 반복 재현성 | 같은 설정 → 같은 명령열 | 2회 비교 |

## 안전
- 최대 속도 제한: ( 10 (실차 1회 확인 시) ) km/h  ← 공통 상한 30 km/h 안에서 단계적으로
- can_guard 클램프: `--steer-limit-deg 15` `--brake-limit-pct 100` `--acc-limit-pct 10`
- 비상정지 담당자:            / 정지 수단: (00 완료 전) stop.sh·can_guard kill + 물리 E-stop
- 종료 절차: **brake 100 유지한 채 stop.sh** (auto 000 금지 — 브레이크 풀림)
- 방향 전환(후진): 사람이 직접, 자율은 전진만
- 반복 횟수: SIL 2회 + 실차 저속 1회
