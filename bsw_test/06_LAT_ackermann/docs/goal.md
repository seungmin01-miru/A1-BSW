## 목적
- 회전 반경으로 실제 유효 타이어각을 역산해 명령 타이어각과 비교한다. 주행 없음 — 05·07(원) 데이터 재사용.

## 입력 (명령 조건)
- 입력 데이터: 05 (핸들 ±150°), 07 원 (핸들 ±30/60/90/120/150°)
- 저속(≤ 10 km/h) 정상 상태 구간만 사용
- 계산: `R = v / 요레이트`, `δ_ack = atan(L / R)`, **L = 2.360 m**
- 명령 타이어각 = 변환표(명령 핸들 °), 실제 핸들각 기반 타이어각도 같이 계산
