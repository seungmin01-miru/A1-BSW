A1 BSW 실차 시험 — 입력 순서 메모 (대회 차량 PC 전용)                         v1 2026-11-04
이유·판단 기준은 FIELD_MANUAL.md. 여기는 "무엇을 어떤 순서로 치나"만.
표기  [T1][T2][T3] = 터미널 번호   lift> = lift_cmd 안에서 입력   <…> = 바꿔 넣을 값
      앱 = 앱 정지 담당   안전 = 물리 E-stop 담당
=============================================================================================

■ 언제든 — 비상 정지
  (앱 담당) 앱 비상 정지 버튼                              # 1순위 (00 통과 후)
  es                                                       # PC 비상 정지 (아무 터미널)
  (안전) 물리 E-stop                                       # 00 통과 전엔 이게 1순위
  esr                                                      # 차가 완전히 선 뒤 해제 → 그다음 down

■ 모든 터미널을 열 때마다 (먼저 한 번)
  source ~/git/A1-BSW/bsw_test/field_env.sh               # up down lc chk gen es esr m app 사용 가능

공통 — 한 세션 (모든 테스트가 이 틀)
=============================================================================================
  [T1] up <테스트ID>_s<번호> <가속한계%>          # 띄우기. 끝에 "✅ 준비 완료" 확인
  [T2] lc …  또는  gen …                           # 명령 도구(둘 중 하나만)
       … 시험 …
  끝  lc 쓴 경우 :  lift> auto brake on
                    lift> brake 100                # 상태줄 브레이크 위치 8.2 확인
                    lift> q
      gen 쓴 경우:  끝내기(브레이크 100 %) 뜬 뒤  q + Enter
  [T1] down                                        # stop.sh
       브레이크 위치 유지되는지 확인 — 풀리면 물리 E-stop + 기록
  ※ 생성기는 1 회차 = 1 세션 (회차마다 up → gen → q → down → 차 복귀)
  ※ 비상 정지 뒤엔:  esr → down → 차 복귀 → up (_s 번호 +1)

00 SAF-ESTOP — 비상 정지 (관문)              상한 10 km/h
=============================================================================================
-- 00-0 앱 버튼 확인 (정지 상태, lc 아직 안 띄움)
  [T1] up SAF-ESTOP-01_s1 10                       # 앱 안 보이면 거부됨 → 앱 연결
  [T3] app                                         # 0x156/0x157 화면 + 저장
  (앱) 10 s 대기 → 정지 버튼 3회(3 s 누름, 5 s 쉼)
  [T2] m 앱 정지 버튼 1  /  m 앱 정지 버튼 2 …     # 누를 때마다
  [T2] grep estop_request ~/a1_race_capture/track_latest/can_guard_events.csv
                                                   # 버튼마다 한 줄 → 없으면 오늘 주행 중단
  [T3] Ctrl+C

-- 00-1 S0 정지 시험 (바퀴 굄) — 회차마다 세션 새로
  [T2] lc --steer-limit-deg 15 --acc-limit-pct 10
  lift> auto on                                    # auto 111, ACTIVE
  r1~r3 : lift> q                                  # 명령 끊김 → HOLDING 30→60 %
  r4~r6 : (앱) 정지 버튼                           # ESTOP 30→82 %
  r7~r9 : es                                       # 〃
  r10   : pkill -9 -f can_guard.py                 # 차량 페일세이프(TODO-2) 시간 기록
  매 회차:  m r<N> <트리거>  →  esr  →  (lc 살아 있으면 brake 100 → q)  →  down  →  up SAF-ESTOP-01_s<N+1> 10

-- 00-2 S1 5 km/h → S2 10 km/h (트리거 각 3회)
  [T2] lc --steer-limit-deg 15 --acc-limit-pct 10
  lift> auto on
  lift> acc 3   (2 s 뒤 자동 0 → 다시 입력, 5 km/h 근처까지 1 % 씩)
  (안전 "지금") → 트리거 (q / 앱 / es)
  [T3] m r<N> 트리거 속도 <km/h>
  정지 후: 정지거리 줄자, 휠락 확인 → esr → down → up …

=============================================================================================
01 LAT-ALIGN — 타이어 정렬                   상한 20 km/h
=============================================================================================
  [T1] up LAT-ALIGN-01_s1 10
  [T2] lc --steer-limit-deg 15 --acc-limit-pct 10 --steer-hold-s 60 --acc-hold-s 30
  lift> auto steer on
  lift> steer 0                                    # 앞바퀴 각도 실측(좌·우) + 상태줄 조향 위치 기록
  lift> auto on
  lift> acc <%>                                    # 10 km/h 근처 유지
  [T3] m r<N> 정방향 시작 … m r<N> 끝 이탈 <cm>
  (직선 끝) lift> acc 0 → lift> brake 30 → 정지 → 공통 "끝" → 사람이 차 돌림 → up _s<N+1>
  왕복 × 3. 보정 후엔 lift> steer <오프셋 핸들°> 넣고 왕복 × 3

02-1 LON-PROF — 생성기 실차 1회 (03 이후 생성기 쓰기 전)      상한 10 km/h
=============================================================================================
  [T2] chk gen_check.yaml --var acc=6              # "✅ 검사 통과" 확인 (00-2 에서 찾은 5 km/h %)
  [T1] up LON-PROF-01_s1 10
  [T2] gen gen_check.yaml LON-PROF-01_r1 --var acc=6
       대기 표시 → (안전 "비었음") → Enter          # 사다리꼴 8 s → 끝내기 자동
       화면: 명령 값 = 0x210 값, 차속 보임 확인
       끝내기 뜬 뒤 q + Enter
  [T1] down
  ※ 실행 중 아무 줄 Enter 또는 Ctrl+C = 즉시 끝내기(가속 0, 브레이크 100 %)

03(a) LON-ACC — 가속 % 계단                  상한 30 km/h     회차마다 세션 새로
=============================================================================================
  불감대:  chk acc_step.yaml --var acc=3 --var t=5
           up LON-ACC-01_s<N> 3
           gen acc_step.yaml LON-ACC-01_r<N> --var acc=3 --var t=5     → 안 움직이면 4, 5 … (1 % 씩)
  계단  :  up LON-ACC-01_s<N> <acc>                                     # 가속 한계 = acc 와 같게
           gen acc_step.yaml LON-ACC-01_r<N> --var acc=<10|15|20|25|30> --var t=10
                                                   # 30 km/h 닿으면 자동 끝내기. 각 % 3회, 약한 것부터
  매 회차: m r<N> 최고 속도 <km/h>  →  q  →  down  →  차 복귀
  그날 끝: python3 ~/git/A1-BSW/tools/track_day/fit_maps.py long <세션>/bag     # accel_map 후보 (GNSS 녹화 필요)

=============================================================================================
04(a) LON-DEC — 브레이크 % 계단              회차마다 세션 새로
=============================================================================================
  up LON-DEC-01_s<N> <acc>
  gen brake_step.yaml LON-DEC-01_r<N> --var acc=<03에서 찾은 %> --var v=<10|20|30> --var vmax=<v+5, 최대 30> --var brake=<%>
                                                   # v 도달 → 가속 0 + 브레이크 % 8 s → 끝내기 100 %
       10 km/h: brake 20 40 60 82 100 / 20 km/h: 20 40 60 82 100 / 30 km/h: 40 60 82 100  (각 3회, 약한 것부터)
  m r<N> <v>kph brake <%> 정지거리 <m>  →  q  →  down  →  차 복귀
  ※ "until_speed 시간 초과" = 20 s 안에 v 못 감 → acc 올려서 다시

=============================================================================================
05 LAT-MAXSTEER — 최대 조향 원선회           상한 10 km/h     지름 15 m 이상 비움
=============================================================================================
  chk steer_circle.yaml --var deg=150 --var acc=6
  up LAT-MAXSTEER-01_s<N> <acc>
  gen steer_circle.yaml LAT-MAXSTEER-01_r<N> --var deg=150  --var acc=<%> --var t=40     # 좌, 3회
  gen steer_circle.yaml LAT-MAXSTEER-01_r<N> --var deg=-150 --var acc=<%> --var t=40     # 우, 3회
                                                   # 정지에서 핸들 돌림(2.5 s) → 3 s → 출발 → 40 s → 끝내기
  m r<N> 좌/우 지름 <m> (콘 4개 줄자)  →  q  →  down

=============================================================================================
07 LAT-PROF — 원 / 나선 / 사인               02-1 통과 후     회차마다 세션 새로
=============================================================================================
  원  : gen steer_circle.yaml LAT-PROF-01_r<N> --var deg=<±30|60|90|120|150> --var acc=<%> --var t=<s>   # 각 2회
  나선: chk steer_spiral.yaml --var deg=150
        gen steer_spiral.yaml LAT-PROF-01_r<N> --var deg=150  --var acc=<%>               # 좌 2회 (0→150°, 10 °/s)
        gen steer_spiral.yaml LAT-PROF-01_r<N> --var deg=-150 --var acc=<%>               # 우 2회
  사인: chk steer_sine.yaml --var freq=0.5
        gen steer_sine.yaml LAT-PROF-01_r<N> --var freq=0.1 --var cycles=2 --var acc=<%>  # 각 주파수 2회
        gen steer_sine.yaml LAT-PROF-01_r<N> --var freq=0.2 --var acc=<%>
        gen steer_sine.yaml LAT-PROF-01_r<N> --var freq=0.5 --var acc=<%>
  (up 은 매번:  up LAT-PROF-01_s<N> <acc>)

막히면
=============================================================================================
  "다른 0x210" 거부        → 원격 유닛 끄기
  "앱 … 안 보임" 거부       → 앱 연결. 00-0 전이면 up … --estop-required 빼고 프레임부터(FIELD_MANUAL 7절)
  lc 띄웠는데 0x210 없음    → lift> auto on 안 함(정상)
  gen "다른 명령 도구 실행 중" → lc 를 q 로 끄거나 down
  gen "0x201 차속이 안 보임" → Kvaser·kv0 확인, 시작 거부는 정상 보호
  gen "상한 위반"          → --var 값이 yaml limits 밖. 값 낮추기
  ESTOP 인데 브레이크 안 오름 → 물리 E-stop, 그날 중단
  속도 상한 넘음           → lc: acc 0 + brake 30 / gen: Enter → 안 서면 es → 앱 → 물리
