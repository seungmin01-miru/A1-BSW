# BSW 실차 주행 테스트 계획서

- 작성일: 2026-11-04
- 범위: 종방향(직선 감가속) / 횡방향(조향) 실차 주행 데이터 추출 및 성능 확인
- 진행 순서: `00 → 01 → 02 → 03 → 04 → 05 → 06 → 07`
  - 00(비상 정지), 01(타이어 정렬)은 모든 주행 테스트의 선행 조건
  - 06은 05·07 데이터를 재사용하여 분석만 수행
- 기대 결과값의 숫자는 **초기 가정치**이며, 첫 주행 결과를 보고 조정한다.

## 2. 공통 기준

### 2.1 기록 신호표

| 분류 | 신호 | 용도 |
|---|---|---|
| 명령 | 목표 속도, 스로틀 명령, 브레이크 명령, 목표 조향각 | 입력 기준 |
| 차량 응답 | 바퀴 4개 속도, 실제 조향각(센서), 브레이크 압력 | 실제 반응 |
| 자세 | 요레이트, 가로/세로 가속도 (IMU) | 회전·감가속 분석 |
| 위치 | GNSS 위치·속도 | 경로, 옆으로 벗어난 양 |
| 상태 | 비상정지 상태, 통신 heartbeat, 오류 코드 | 안전·이상 확인 |

### 2.2 파일 이름 규칙

```
날짜_테스트ID_회차.확장자
예) 20261104_LON-ACC-01_r1.mcap
```

### 2.3 공통 안전 규칙

- 모든 주행 테스트는 00(비상 정지) 검증 완료 후 진행
- 속도는 저속 → 중속 순서로 단계적으로 올림
- 테스트마다 최대 속도 제한값과 비상정지 담당자를 지정

## 3. 테스트별 요구사항

### 00. 비상 정지 fallback (SAF-ESTOP)
- **개요:** 통신 끊김 또는 비상 버튼 입력 시 자동 제동
- **목적:** 무인 속도 테스트 전 안전 확보
- **기대 결과:** 통신 끊김 감지 ≤ 100 ms, 제동 시작 ≤ 200 ms, 작동률 100%
- **핵심 요구사항:**
  - heartbeat 시간 초과 판단 로직
  - 저속(≤ 10 km/h)에서 먼저 검증
  - 모든 주행 테스트의 선행 조건

### 01. 타이어 정렬 확인 및 보정량 (LAT-ALIGN) — 우선순위 1
- **개요:** 조향 0도 직진 시 쏠림 측정 → 소프트웨어 조향 오프셋 계산
- **목적:** 모든 종·횡방향 데이터의 "0도 기준" 확보
- **기대 결과:**
  - 보정 후 요레이트 평균 ±0.5 deg/s 이내
  - 100 m 직진 시 옆으로 벗어난 양 ≤ 0.5 m
- **핵심 요구사항:**
  - 정지 상태에서 바퀴 방향 측정
  - 왕복 주행으로 노면 기울기 영향 제거
  - 보정 전·후 비교

### 02. 목표속도 프로파일 생성 (LON-PROF) — 우선순위 2
- **개요:** 계단형·램프형·사다리꼴 목표속도 명령 생성기
- **목적:** 가속·감속 테스트에 같은 입력을 반복해서 넣기 위함
- **기대 결과:** 3종 프로파일을 설정값(목표속도, 기울기, 유지 시간)만 바꿔 재사용 가능
- **핵심 요구사항:**
  - 최대 속도 제한 내장
  - 명령값도 함께 로그에 기록

### 03. 가속 추종 성능 (LON-ACC)
- **개요:** 목표속도 프로파일 입력 → 실제 속도가 얼마나 잘 따라가는지 측정
- **목적:** 구동 계통 반응 특성 파악
- **기대 결과:**
  - 반응 지연 ≤ 0.3 s
  - 오버슈트(목표 초과) ≤ 10%
  - 정속 오차 ±1 km/h
- **핵심 요구사항:**
  - 목표 vs 실제 속도 그래프 + 오차 그래프 자동 생성
  - 속도 단계적 증가, 3회 반복

### 04. 감속 추종 성능 (LON-DEC)
- **개요:** 감속 명령 → 실제 감속·정지 측정
- **목적:** 제동 계통 반응 특성과 정지 거리 파악
- **기대 결과:**
  - 제동 지연 ≤ 0.3 s
  - 목표 감속도 대비 오차 ≤ 10%
  - 같은 조건 정지 거리 편차 ≤ 5%
- **핵심 요구사항:**
  - 브레이크 압력 기록
  - 감속도·정지 거리 자동 계산, 3회 반복

### 05. 최대 조향 정속 주행 (LAT-MAXSTEER) — 우선순위 3
- **개요:** 최대 조향각 고정 + 저속 정속 원선회
- **목적:** 최소 회전 반경과 조향 한계 확인
- **기대 결과:**
  - 좌·우 최소 회전 반경 측정
  - 반복 편차 ≤ 5%, 좌우 차이 확인
- **핵심 요구사항:**
  - 저속 주행 (타이어 미끄러짐 방지)
  - 좌·우 각각 측정, GNSS 궤적 + 요레이트 기록

### 06. 목표 조향각 vs 에커먼 조향각 (LAT-ACK)
- **개요:** 회전 반경으로 실제 유효 조향각을 거꾸로 계산 → 명령값과 비교
- **목적:** 조향 명령과 실제 바퀴 각도 사이의 오차 파악
- **기대 결과:** 조향각별 오차표, 오차 ≤ 1~2도
- **핵심 요구사항:**
  - 05·07(원) 데이터 재사용
  - 계산식: `R = 속도 / 요레이트`, `δ ≈ atan(휠베이스 / R)`
  - 저속 데이터만 사용

### 07. 조향 프로파일 (LAT-PROF)
- **개요:** 원(고정 조향), 나선(조향 점점 증가), 사인파(좌우 반복) 입력
- **목적:** 조향각–회전 반경 관계표, 조향 반응 지연 파악
- **기대 결과:**
  - 조향각별 회전 반경표
  - 사인파 주기별 지연 시간 · 반응 크기 비율
- **핵심 요구사항:**
  - 02와 같은 방식의 프로파일 생성기 재사용
  - 명령 조향각 + 실제 조향각 동시 기록
