## 입력 (명령 조건)
| 방향 | 핸들 ° | 속도 | 바퀴 수 | 횟수 |
|---|---|---|---|---|
| 좌 | +150 (명령 한계) | 5 km/h | 원 2바퀴 이상 정상 상태 | 3 |
| 우 | −150 | 5 km/h | 원 2바퀴 이상 정상 상태 | 3 |
- 정지 상태에서 조향을 먼저 끝까지 돌린 뒤 출발 (조향 속도 영향 제거)
- **도는 방향**: 좌 = 핸들 +150 = **반시계**(위에서 볼 때), 우 = −150 = **시계**. 좌 3회 → 우 3회 순서(부호는 01-1 에서 `steer +30` = 왼쪽 확인 후).
- v2(2026-11-04): 속도는 폐루프 5 km/h(`steer_circle_speed.yaml --ctrl …`), 오프셋이 있으면 `deg = 150 − 오프셋`(좌) / `−150 − 오프셋`(우) — 합이 150 을 못 넘음.
  05 는 **유지**(사용자 결정 11-04) — 07 나선만으로는 정상 상태 원이 안 나와 06 분석이 약함.
