## 목적
- (a) 브레이크 % ↔ 감속도(m/s²) 변환표와 정지 거리를 만든다.
- (b) 목표 감속도 추종 성능을 측정한다.

## 전제 조건
- [ ] 00 비상 정지 검증 완료
- [ ] 01 타이어 정렬 보정 완료
- [ ] 02 생성기 단계 1 완료
- [ ] 03 (a) 로 정속 유지 가속 % 확보

## 입력 (명령 조건)
**(a) 개루프 — 먼저**
| 시작 속도 | 브레이크 % 계단 | 횟수 |
|---|---|---|
| 10 km/h | 20, 40, 60, 82, 100 % | 각 3 |
| 20 km/h | ~~20~~, 40, 60, 82, 100 % | 각 3 |
| 30 km/h | 82, 100 % 1회 먼저 → 50 m 안에 서면 나머지 | (각 3) |
- **코스 50 m(2026-11-04)**: 20 km/h·20 % 는 잠정 brake_map(약 0.55 m/s²) 기준 정지에 약 28 m ★ + 가속 구간 → 50 m 초과라 뺀다. 30 km/h 는 가속만 약 25 m ★.
  코스 끝 예측이면 생성기가 끝내기(브레이크 100)로 바꾼다 → 그 회차는 % 표에서 끝내기 이후 구간을 뺀다.
- 가속 0 % 로 바꾸는 동시에 브레이크 계단, 정지까지 유지. 위치는 82 % 에서 포화 — 100 % 는 확인용
- 결과 → `fit_maps.py` → `track.yaml` (브레이크 표 상한 82 %)

**(b) 폐루프** — 목표 감속도 1.0 / 2.0 / 3.0 m/s², 각 3회 — `decel_ramp.yaml --ctrl … --var v=15 --sweep rate=3.6,7.2,10.8`(목표 차속 기울기 = 감속도 × 3.6)
